# Book: quiet-cheer

- behavior_target: 課堂情緒激動時大聲叫喊（答對、遊戲贏了、太興奮時瞬間爆音）——安裝「抓住喊聲 → 握拳擠壓 → 無聲歡呼」的尖峰替代腳本；核心哲學：興奮是好的，要換的是**出口**不是熱情（2026-08 老師來信：參與度高、情緒投入，激動時偶有大聲叫喊）
- cue_phrase: "Quiet cheer!"（完整口訣：Catch the shout → Squeeze my fists → Quiet cheer）
- new_vocabulary: [shout, squeeze, fist]
- status: published（PDF + site，2026-08）
- 角色：Tr. Mina（老師，真實人物，提醒溫和不責備）；被嚇到的同學用**不具名 kid()**（不把真實朋友畫成受害者）
- 與既有口訣的分工：**Volume down = 音量漸漸變大**（慢漂移，自我察覺後轉小）；**Quiet cheer = 興奮尖峰的瞬間爆音**（大叫換成無聲歡呼）——漂移用調節、尖峰用替代動作，兩顆不同肌肉。另與 **Save it!**（有答案想搶說）區隔：Save it 是「內容」想衝出口、Quiet cheer 是「音量/情緒」想衝出口
- 核心意象：**喊聲小怪獸**——興奮時一隻紅色小聲波怪從喉嚨往上衝；抓住牠、塞進握緊的拳頭裡，拳頭發光 → 打開變成滿手小星星（無聲歡呼的樣子）——能量沒有消失，只是變形
- 無聲歡呼的具體動作（p6/p8 要畫清楚）：雙拳用力一握 → 雙手快速揮動＋嘴巴大大的「YES!」嘴型但零聲音＋原地小跳
- 場景：學校教室（問答時間/小組遊戲）；服裝全書白 T
- 設計備註：p1 先肯定熱情（I get SO excited!）；p4 爆音後同學摀耳朵但**不畫責備臉**、Tr. Mina 提醒手勢溫和（食指輕靠嘴）；絕不出現「噓你很吵」的羞辱畫面

## Parent page notes

標準六條（第 2 條固定：**出事後絕對不拿出來讀**——在學校大叫被反映的當天不讀不罵，平靜時讀），另加本書特有三條：
1. **在家把無聲歡呼練成反射**：看比賽、玩遊戲、他答對任何事的時候，全家一起做「quiet cheer」（揮拳、原地跳、誇張嘴型都可以，就是零聲音）——激動當下大腦來不及思考，只提取得出練過一百次的動作。練習時越浮誇越好，讓他覺得無聲版一樣爽。
2. **與 Tr. Mina 對暗號**：請老師提醒時只說 "Quiet cheer!"（指向替代動作，不說「不要叫」）；並區分兩個口訣——聲音漸漸變大用 "Volume down!"、興奮瞬間爆音用 "Quiet cheer!"，是兩顆不同的肌肉。
3. 當他主動說 "A shout jumps up my throat"、或爆音後自己改成無聲歡呼 = 覺察里程碑，大力稱讚（**補救也算成功**——從爆音到自我修正就是進步）。
