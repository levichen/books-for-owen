# Book: little-teacher

- behavior_target: 課堂內容太簡單時的自大反應（喊 "So easy!"、炫耀、覺得都會了就不聽課）——安裝「抓住炫耀 → 想起我只是先出發 → 當小老師幫忙」的重新框架腳本；核心設計：**不否認他的能力**（能力是真的、且來自練習），把「想被看見」的需求從炫耀改道到「小老師」的榮譽身份（2026-08 背景：三年全美＋1.5 年珠心算，上小一後部分課程對他太簡單）
- cue_phrase: "Little teacher!"（完整口訣：Catch my brag → Remember my head start → Help like a teacher）
- new_vocabulary: [easy, brag]
- status: draft
- 角色：Tr. Mina（老師，真實人物——小幫手要經她同意）；還在學的同學用**不具名 kid()**（不把真實朋友固定在「不會」的位置）
- 與既有口訣的分工：**Save it!** = 有「答案」想搶說（內容衝出口）；**Quiet cheer** = 「興奮」想爆音；**Little teacher** = 「我都會了」的優越感想衝出口——嘴巴家族第三兄弟，處理的是心態不是音量。與 **Ask first** 連動：幫忙前先問（p6③ 與家長頁明文呼應）
- 核心意象：**同一條跑道**——大家跑同一條學習之路，Owen 只是**先出發**（head start），後面的朋友正在跑來，不是跑不到；「會的人」在路邊當加油的小老師，不是站在前面嘲笑
- 關鍵歸因（全書貫穿）：會＝因為**先練過**（I practiced early），不是天生聰明——p1 開場就定調
- 場景：小一教室（Tr. Mina 教簡單的數學/字母）；p5 星空跑道意象
- 服裝備註：全書白 T
- 設計備註：p4 不羞辱——喊 So easy 後同學的難過用低頭畫面表達、Tr. Mina 停頓但不責罵；p8 幫忙前先舉手問過 Tr. Mina（示範規矩：老師同意＋同學願意才教）

## Parent page notes

標準六條（第 2 條固定：**出事後絕對不拿出來讀**——被反映上課喊無聊/炫耀的當天不讀不罵，平靜時讀），另加本書特有三條：
1. **歸因改造（本書的地基）**：在家把「你好聰明」換成「你練了很久所以會」——自大長在「我天生聰明」的身份上，練習歸因才長得出謙虛。他嫌簡單時不否認，回「對，因為你先練過——那這題你能做得更快更漂亮嗎？」把太簡單導向精益求精（珠心算精神），而不是導向無聊。
2. **與 Tr. Mina 對暗號**：他喊 So easy 或坐不住時提醒 "Little teacher?"——是邀請進入幫手身份，不是斥責；同時跟老師約好小幫手的規矩：**老師同意＋同學願意**才教（沒人想被硬教），與 Ask first 同一顆「先問」肌肉。
3. 當他主動說 "'So easy' jumps to my mouth"、或輕聲幫了同學一題 = 覺察里程碑，大力稱讚——稱讚點放在「你幫他學會了」（親社會成就）而不是「你好棒都會」（能力展示），持續把「被看見」餵給對的行為。
